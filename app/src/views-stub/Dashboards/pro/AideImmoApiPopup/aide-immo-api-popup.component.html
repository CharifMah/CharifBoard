Étape 1 : Accéder à l'onglet "Communiquer"

Connectez-vous à votre espace professionnel Immodvisor.

Dans le menu principal situé en haut de la page, cliquez sur l'onglet "Communiquer".

Cet espace vous permet d'accéder à tous les outils de diffusion de vos avis clients, notamment les visuels, widgets et supports à intégrer sur votre page SellMatch.

Étape 2 : Accéder à la section "Widgets"

Une fois dans l'onglet "Communiquer", cliquez sur "Widgets" dans le menu secondaire.

Cette section vous permet d'accéder aux différents formats d'affichage de vos avis clients (notes, recommandations, avis détaillés...) que vous pourrez intégrer sur votre page SellMatch.

Étape 3 : Sélectionner le widget "Pied de page"

Dans la liste des widgets disponibles, repérez le widget "Pied de page".

Cliquez ensuite sur le bouton "J'installe le widget" afin de sélectionner ce format.

Ce widget est idéal pour afficher votre note, vos étoiles et le nombre d'avis de manière claire et rassurante sur votre page SellMatch.

Étape 4 : Récupérer l'identifiant Immodvisor

Une fois le widget ouvert, repérez le champ "Lien du bouton Immodvisor" dans la partie droite.

Vous y trouverez une URL similaire à celle-ci :

https://www.immodvisor.com/pro/iad-france-karim-mahmoud-sete-34200-81133.html

Votre objectif est de récupérer les 5 derniers chiffres de ce lien.

Dans cet exemple : 81133

Cet identifiant est essentiel pour connecter correctement vos avis à votre page SellMatch.

Étape 5 : Installer le widget

Une fois l'identifiant récupéré, cliquez sur le bouton "J'installe le widget" en bas à droite de l'écran.

Cette action permet de générer le widget et de finaliser sa configuration côté Immodvisor.

Étape 6 : Récupérer la clé Widget

Après avoir cliqué sur "J'installe le widget", une fenêtre s'ouvre avec le code d'intégration.

Repérez la ligne :

"Votre clé Widget"

Elle se présente sous forme d'un code (lettres + chiffres), par exemple :

W9T1-SUPIO-IDGR-03NJK-JYMV6B

Copiez cette clé, elle sera nécessaire pour connecter vos avis à votre page SellMatch.

Étape 7 : Accéder à la modification de votre profil SellMatch

Connectez-vous à votre espace sur SellMatch.

Dans le menu à gauche, cliquez sur "Profil", puis sur le bouton "Modifier" situé en haut à droite de la page.

Cela vous permet d'accéder aux paramètres de votre profil afin d'y intégrer vos avis Immodvisor.

Étape 8 : Intégrer vos informations Immodvisor

Dans la page de modification de votre profil, descendez légèrement.

Vous pouvez maintenant renseigner :

  • Votre identifiant Immodvisor (5 chiffres) dans le champ "Identifiant entreprise Immodvisor"
  • Votre clé Widget (API) dans le champ "Clé API Immodvisor"

Une fois les informations renseignées :

  1. Cliquez sur Enregistrer
  2. Rechargez la page

Félicitations !

Vos avis Immodvisor sont désormais automatiquement affichés sur votre profil SellMatch et visibles par les vendeurs lors de vos candidatures.

Votre profil est maintenant optimisé pour convertir davantage de vendeurs grâce à la preuve sociale de vos avis clients.
