Variante default + pleine largeur

Look "carte" avec fond translucide, blur et ombre. Chaque onglet occupe l'espace disponible.

Variante pills

Boutons en forme de pilule (border-radius 50px), pas de fond de carte. Idéal pour une navigation principale.

Variante underline

Sélecteur underline 2px, fond transparent. Style minimaliste, courant pour les sous-sections.

Mode fullWidth=false (auto-fit)

Les boutons prennent la place de leur contenu. Utile pour des barres d'onglets courtes.

Tailles sm / md / lg

Trois tailles disponibles, la taille md est la valeur par défaut.

Position de l'icône left / right / top

L'icône peut être placée à gauche (défaut), à droite ou au-dessus du label.

État disabled

Un onglet peut être désactivé (non cliquable) via la propriété disabled: true.

Sans icônes

Mode texte uniquement, showIcons=false. Les labels sont affichés seuls.

Badges colorés

Les badges changent automatiquement de couleur selon l'identifiant de l'onglet (urgent, new, hot, premium, selected, ou info par défaut).
