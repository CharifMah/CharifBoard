Fin du parcours #demo-finish

Dernière étape (placement: top). Cliquer "Terminer" appelle Tutorial.Complete() qui marque done=true en localStorage et ferme l'overlay.

Le service est un singleton Angular (providedIn: 'root') — l'injecter n'importe où donne la même instance que celle utilisée par <app-tutorial-overlay>.
  • Selector : sélecteur CSS spotlighé dans la vue courante. Si null ou non trouvé, le spotlight couvre toute la zone de contenu.
  • NavigateTo : nom de vue à atteindre AVANT l'étape (déclenché via le callback TutorialService.OnViewChange).
  • Placement : position préférée du tooltip. Le composant flip automatiquement pour rester visible.
