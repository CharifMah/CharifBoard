API Stripe (Subscription)

Le backend expose api/Subscription (BaseApiController<UserSubscriptionsDTO>) : la création de la souscription en BDD ET de la session Stripe Checkout Embedded sont gérées par les hooks ServiceBase de UserSubscriptionsService.

POST /api/Subscription/Create

Crée la souscription en BDD + la session Stripe Checkout Embedded.

body: { userId, planId, billingPeriod }

Retourne le DTO enrichi avec stripeSessionId et stripeClientSecret.

GET /api/Subscription/my

Récupère l'abonnement actif de l'utilisateur connecté.

POST /api/Subscription/cancel

Annule l'abonnement actif (fin de période, propage côté Stripe).
